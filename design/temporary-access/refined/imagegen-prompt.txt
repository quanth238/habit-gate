Use case: ui-mockup.
Asset type: high-fidelity design reference for an existing lightweight native macOS app named Habit Gate.
Primary request: Redesign the Temporary access page into a calm, polished, professional focus timer. Show two complete 880 x 680 macOS app windows side by side: Ready and Active. This is a design concept with illustrative data, not a real screenshot.
Style: refined native macOS utility, system typography, disciplined spacing, crisp hairlines, flat colors, restrained sapphire-blue accent, charcoal and soft slate surfaces, warm-white text. Sophisticated, quiet, inviting. No glossy effects or futuristic styling. Realistic macOS window traffic lights.
Structure: slim 196-point left sidebar, small blue shield and Habit Gate wordmark, navigation Overview / Essential habits / Websites / Mac apps / Temporary access / Connection / Settings, Temporary access selected with a subtle blue tint. Small connected status at sidebar bottom. Main area uses a single spacious canvas, NOT a giant enclosing card. Top left medium heading Temporary access and the one-line subtitle A little time for what you need. Top right a small 15 min daily chip. Center an elegant thin 3-point blue circular dial with subtle twelve hour ticks, generous empty space inside, large beautifully spaced tabular digits. Inside ready dial: 15:00, small remaining today; tiny Ready label above digits. Below dial one compact rounded blue button, only 200 points wide, text Start access and small play symbol. A quiet single line below reads Your unused time stays yours. At bottom of content a compact separated strip: label For your blocked apps, four small real recognizable app icons for Telegram, WhatsApp, Zalo, Discord, no GeForce. One quiet line Resets at 4 AM · Websites stay protected, a small gear shortcut. A thin understated footer can show Verified just now and Open Habitify.
Active window has the exact same layout and proportions, blue dial at about 80%, tiny Access on label above digits, timer 12:43, small remaining today, compact same-blue End access button with stop symbol, a short line End access to save time for later. A small quiet Ends at 14:30 replaces Ready caption if useful, do not add more information. All key controls must fit, with balanced vertical whitespace.
Constraints: Strong typographic hierarchy; only one primary action per window; blue accent consistent across shield, selected nav, dial, and button. State indicated by text as well as color. No app selector, no duration presets, no +5 button, no pause, no extra time, no charts, no gradients, no shadows inside the content, no repeated explanations, no giant full-width button, no heavy giant card around the dial, no advertising, no decorative illustrations. Keep it implementable with native SwiftUI shapes and text, no bitmap UI backgrounds. Crisp readable UI labels, straight-on product design presentation, neutral background outside the windows.
