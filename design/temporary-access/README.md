# Daily allowance UI evidence

Native 1.5.0 uses one shared daily foreground-use allowance. The installed screenshot captures the actual app after Keychain approval. The two 880×680 previews use production views with isolated fixture state; their credential labels are illustrative and no Keychain or personal Habitify data is loaded.

The design keeps the existing adaptive palette, shield, real Mac icons and native controls. The balance and counting/paused state lead; duration settings apply to the next daily reset. The UI has no session start, end or extra-time controls.

See [the feature specification and flow](../../docs/DAILY-ACCESS.md) for behavior and validation. Earlier session-based concept images were retained privately as design history and are not runtime assets.
