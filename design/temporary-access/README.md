# Daily access UI evidence

Current 1.5.1 screenshots are in `manual/`: the main countdown, access enabled with an End action, and allowance editing in Settings. These capture the installed app with its real preserved daily balance and live connection.

The older images in this folder document the 1.5.0 automatic-access layout. Its minimum-size previews used isolated illustrative state and did not read credentials. See [the current specification and flow](../../docs/DAILY-ACCESS.md).
